Vigtigt ift. Vue

Når Vue kører på fx localhost:5173 og backend på localhost:3000, skal frontend bruge:

    credentials: "include"

Ellers sendes session-cookie ikke med.

Eksempel:

const csrfResponse = await fetch("http://localhost:3000/csrf-token", {
  credentials: "include",
});

const { csrfToken } = await csrfResponse.json();

const loginResponse = await fetch("http://localhost:3000/auth/login", {
  method: "POST",
  credentials: "include",
  headers: {
    "Content-Type": "application/json",
    "x-csrf-token": csrfToken,
  },
  body: JSON.stringify({
    username,
    password,
  }),
});
